REST API & Full-Stack Prioritas Utama #1

Sistem Informasi Harga Pangan

Aplikasi web untuk mendata dan memantau informasi harga komoditas pangan beserta pengelolaan stok dan kategorinya. Dibangun dengan memisahkan arsitektur penyedia data dan antarmuka admin yang terlindungi autentikasi.

Problem

Kebutuhan sistem terpusat untuk mencatat fluktuasi harga bahan pangan, pengelompokan kategori komoditas, dan pemantauan stok secara akurat oleh pengelola data.

Solution

Membangun sistem web dengan arsitektur REST API, dilengkapi modul autentikasi admin dan panel pengelolaan inventaris pangan.

My Role

Backend Developer, Database Designer, dan UI Designer (merancang mock-up antarmuka di Figma).

Development Process

Merancang UI di Figma → Menyusun skema tabel MySQL → Mengimplementasikan logika backend dan endpoint REST API → Pengujian alur autentikasi admin.

Fitur-Fitur Utama:
  • Autentikasi dan login admin yang aman
  • Manajemen komoditas pangan (tambah, ubah, hapus)
  • Pengelompokan kategori bahan pangan
  • Pencatatan dan pemantauan stok barang
  • Penyediaan data melalui endpoint REST API
REST API MySQL Figma [PHP / Python]

Web System & API Prioritas #3

Sistem Turnamen E-Sport

Sistem informasi kompetisi e-sport yang memproses alur registrasi peserta serta menyediakan distribusi data turnamen menggunakan PHP dan komunikasi data API.

Problem

Solution

My Role

  • Endpoint API untuk menyediakan informasi jadwal & peserta
